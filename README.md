**The city is yours. The debt isn't.**

An original, top-down coastal crime game. Play as **Sol Vega**, a former courier pulled back into Vista Mar's underworld when a harbor developer takes her family's repair shop. Work with mechanic **Inés Rojas** to steal back the evidence, outrun the patrols, and settle accounts with **Dario Vela**.

Explore a hand-drawn 3,200 × 3,200 city: sixteen blocks, four neighborhoods, markets, rooftop gardens, a waterfront, and the working port. Six story missions connect on-foot exploration, car theft, arcade driving, police escapes, a warehouse shootout, and a final pursuit. Free roam includes garage repairs, courier jobs, collectibles, time trials, and a safehouse. Traffic and pedestrians react to the world; every vehicle is stealable. Everything is original JavaScript and Canvas 2D, including the art and synthesized audio. No libraries, downloads, or build step.

## Controls

| Key | Action |
| --- | --- |
| WASD / arrow keys | Walk; accelerate, brake/reverse, and steer while driving |
| Mouse / left click | Aim / fire pistol |
| Shift | Sprint on foot |
| F | Steal, enter, or exit the nearest vehicle |
| E | Punch; interact with story markers, shops, and activities |
| Space | Handbrake in a car; advance dialogue |
| R | Reload pistol |
| H | Vehicle horn |
| Tab | Full city map |
| Escape | Pause: resume, save, load, controls |
| M | Toggle procedural audio |

## Run

Open `game/index.html` in desktop Chrome, or use the unchanged local server (Node 22+):

```sh
node serve.ts --port 8099
```

Then open **http://localhost:8099/**. Saves use browser localStorage; audio starts after a keypress or click.

## Witnessed screenshots and checks

The four query scenes are deterministic, real game renders: `?shot=start&seed=16`, `?shot=play&seed=16`, `?shot=chase&seed=16`, and `?shot=night&seed=16`. They freeze simulation for a repeatable capture while using the same renderer and world as play.

```sh
node test/syntax.mjs
node test/smoke.mjs
node test/capture.mjs
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Browser tests use the host's existing Playwright module and Chromium executable, with no installation. The output contains the static game, four JPEGs, and a dossier generated by the byte-identical competition library. The recorded development is a linear sequence of milestone commits; the operator pushes after sealing the recording.
